Add the `image.nifti`, `image.dicomweb`, and `image.dicom` file types for single-channel radiology volumes (such as CT and MR) in the `spatialBeta` and `layerControllerBeta` views. DICOM pixel data can be uncompressed or compressed with JPEG Lossless, JPEG-LS, JPEG 2000, HTJ2K, or RLE Lossless.
